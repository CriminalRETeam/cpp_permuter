# Passes

Generated by `cpp_permuter --pass-examples` from the samples in `src/examples.cpp`; a unit test checks this file is up to date. Each example shows a small function and what the pass makes of it (some passes offer more candidates than shown). Most passes also work in the other direction.

## `reorder_saves`

Permute runs of consecutive local saves (declarations and assignments to locals that don't call or store) in every order that keeps dependencies.

```cpp
void Group::f(int idx)
{
    Weapon* a = leader->weapon;
    Weapon* b = list[idx]->weapon;
    Weapon* c = leader->weapon2;
    leader->Copy(list[idx]);
}
```

becomes

```cpp
void Group::f(int idx)
{
    Weapon* a = leader->weapon;
    Weapon* c = leader->weapon2;
    Weapon* b = list[idx]->weapon;
    leader->Copy(list[idx]);
}
```

becomes

```cpp
void Group::f(int idx)
{
    Weapon* c = leader->weapon2;
    Weapon* b = list[idx]->weapon;
    Weapon* a = leader->weapon;
    leader->Copy(list[idx]);
}
```

(5 candidates in all for this function.)

## `move_stmt`

Move a statement up or down past neighbours it doesn't depend on (locals and calls are respected, memory aliasing is not).

```cpp
void f(Ped* p)
{
    p->a = 1;
    p->b = 2;
    g();
}
```

becomes

```cpp
void f(Ped* p)
{
    p->b = 2;
    p->a = 1;
    g();
}
```

## `inline_local`

Remove a local: substitute its initializer into its uses (plain and with a cast), or drop it if unused.

```cpp
void f(Ped* p)
{
    Car* car = p->car;
    car->speed = 0;
}
```

becomes

```cpp
void f(Ped* p)
{
    p->car->speed = 0;
}
```

becomes

```cpp
void f(Ped* p)
{
    ((Car*)(p->car))->speed = 0;
}
```

```cpp
void f(int n)
```

## `flip_compare`

Mirror a comparison: 'a < b' -> 'b > a'.

```cpp

{
    if (p->a < p->b)
        g();
}
```

becomes

```cpp
void f(Ped* p)
{

        g();

```

## `invert_if`

Negate an if condition and swap the then/else branches.

```cpp
void f(Ped* p)
{
    if (p->a == 0)
        g();
    else
        h();
}
```

becomes

```cpp
void f(Ped* p)
{
    if (p->a != 0)
        h();
    else
        g();
}
```

## `ternary`

Turn 'x = c ? a : b' / 'return c ? a : b' into if/else and back.

```cpp
void f(Ped* p, int x)
{
    p->a = x > 0 ? 1 : 2;
}
```

becomes

```cpp
void f(Ped* p, int x)
{
    if (x > 0)
    {
        p->a = 1;
    }
    else
    {
        p->a = 2;
    }
}
```

## `ternary_arg`

'f(c ? a : b);' <-> 'if (c) f(a); else f(b);': a ternary inside a statement, and two branches that differ in one sub-expression.

```cpp
void f(Ped* p)
{
    p->Set(p->state == 0 ? 1 : 0);
}
```

becomes

```cpp
void f(Ped* p)
{
    if (p->state == 0)
    {
        p->Set(1);
    }
    else
    {
        p->Set(0);
    }
}
```

## `switch_if`

'if (x == K) S else D' <-> 'switch (x) { case K: S break; default: D }'.

```cpp
void f(Ped* p, int notify)
{
    if (notify == 1)
    {
        g(p->a);
    }
}
```

becomes

```cpp
void f(Ped* p, int notify)
{
    switch (notify)
    {
        case 1:
            g(p->a);
            break;
    }
}
```

## `cond_split`

'if (a && b) S' <-> 'if (a) { if (b) S }'.

## `loop_form`

for <-> while: 'for (i; c; s) B' <-> 'i; while (c) { B s; }', 'while (c)' <-> 'for (; c;)'.

```cpp
void f(Ped* p)
{
    for (int i = 0; i < p->count; i++)
    {
        g(i);
    }
}
```

becomes

```cpp
void f(Ped* p)
{
    int i = 0;
    while (i < p->count)
    {
        g(i);
        i++;
    }
}
```

## `scope_block`

```cpp

    {
        int x = p->a;
        g(x);
```

## `reorder_cases`

Reorder a switch's case groups (case bodies are laid out in source order).

```cpp
int f(int n)
{
    switch (n)
    {
        case 1:
            return g(1);
        case 2:
            return g(2);
    }
    return 0;
}
```

becomes

```cpp
int f(int n)
{
    switch (n)
    {
        case 2:
            return g(2);
        case 1:
            return g(1);
    }
    return 0;
}
```

## `use_getter`

```cpp
{
    return p->field_1AC_cam.x;
}
```

```cpp

    return p->get_cam_x();

```

## `named_op`

'a * b' <-> 'a.Multiply_408680(b)', '-a' <-> 'a.Negate_4086A0()' for the operators given with --op-alias: whether VC6 inlines the operator.

With `--op-alias '*=Multiply_408680' --op-alias neg=Negate_4086A0`:

```cpp
Fix16 f(Fix16 a, Fix16 b)
{
    return -a * b;
}
```

becomes

```cpp
Fix16 f(Fix16 a, Fix16 b)
{
    return (-a).Multiply_408680(b);
}
```

becomes

```cpp
Fix16 f(Fix16 a, Fix16 b)
{
    return a.Negate_4086A0() * b;
}
```
